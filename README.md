# Naver blog automation

ChatGPT writes verified Korean broadcast-food blog content; the user adds photos and publishes. Codex will build and test **draft saving only**.

## Quick start (Windows)
1. Install Python 3.11+ and run `pip install -r requirements.txt`.
2. Run `python open_editor.py` to open a dedicated local Chrome profile and log into Naver manually.
3. Do not put Naver passwords, cookies, or browser profiles into Git.
4. See `CODEX_TASK.md` for the Codex implementation brief. **Saving is not implemented yet.**

Repository visibility is PUBLIC. Never commit personal data or unpublished manuscripts.
